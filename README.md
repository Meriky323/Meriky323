### InsightFlow AI · 把分散的消费者信号变成可验证的决策

跨境运营里，真正麻烦的往往不是“没有信息”，而是信息散落在商品页、评论、视频、搜索趋势和竞品中，人工整理很慢，最后又容易回到经验判断。

我做了 **InsightFlow AI**：聚合真实市场信号，把消费者反馈拆成需求、购买驱动、购买障碍与使用场景，再连接到产品机会、内容方向和 GTM 下一步动作。

- 多来源证据：Google Shopping、Walmart、YouTube、Google Trends、公开社区讨论
- 证据优先：保留原始来源，不把 LLM 总结直接当成事实
- 两类输出：**产品 / 供给动作** + **内容 / GTM 动作**
- 案例：Magnetic Power Bank · US/AU；Insta360 X6 Launch Intelligence

👉 [查看项目](https://github.com/Meriky323/insightflow-ai)

### 合住 Homi · 从合租摩擦到生活协作原型

合租里的难题不仅是分摊金额，还有催款尴尬、清洁责任不清和重复采购。我用 AI Coding 搭建了 **合住 Homi**，把费用 AA、值日、公共用品和室友公约放进同一个工作台。

- 以“低库存 → 认领采购 → 补充库存 → 生成 AA 账单”串联核心流程
- 按用品特点区分数量与粗粒度状态，降低登记负担
- 通过演示身份切换体验任务完成与公约投票

**当前为浏览器本地交互原型**，未接入真实多人同步或支付；后续能力以预览入口呈现，具体边界见项目说明。

### Link Checker · 把邮件上线前的人工质检变成自动校验

在 EDM 活动上线前，UTM、折扣码、跳转链接和站点错误都需要反复人工检查。这个过程机械、耗时，但一个小错误就可能直接影响 Campaign 转化。

我把这段真实运营流程做成了一个网页工具：

- 自动检查 UTM / Campaign 参数
- 检查折扣码与跳转链路
- 识别嵌套链接、短链与目标站点
- 支持可选的浏览器真实打开检查
- 输出检查结果，减少上线前重复核对

👉 [查看项目](https://github.com/Meriky323/link-checker)

## 我关注的问题

**消费者真正为什么买 / 为什么不买？**  
比“正面还是负面”更重要的是：购买驱动、阻碍、使用场景和用户愿意接受的取舍。

**运营判断能不能被复用？**  
如果一个流程每周都要重复做，我会想它能不能变成模板、SOP、脚本或小工具。

**AI 输出能不能被验证？**  
我更喜欢“证据 → 洞察 → 行动 → 下一步验证”，而不是“让模型生成一个看起来很完整的答案”。
