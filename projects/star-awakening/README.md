# 星辉觉醒 · Real-World Magical Transformation

一个基于浏览器摄像头的真人魔法变身视觉交互原型。

## 核心体验

用户面对摄像头，按照连续动作完成六阶段变身：

1. 双手交叉胸前 → 魔法核心觉醒
2. 双臂向左右展开 → 召唤上装
3. 右手在腰间画圈 → 召唤裙摆
4. 向前踏步并轻点脚尖 → 唤醒战靴
5. 单手举过头顶并旋转手腕 → 星月加冕
6. 转身后完成最终姿势 → 光翼、星尘与终极定格

## 当前版本

目前仓库中提供的是可直接在浏览器打开的视觉交互 Prototype：

- 支持调用浏览器摄像头
- 提供六阶段变身流程与状态切换
- 提供水晶核心、魔法阵、服装层、粒子和终极光翼等视觉反馈
- 即使摄像头权限不可用，也可以手动预览完整流程

## 下一步计划

- 接入 MediaPipe Pose / Hands，自动识别姿态与手势
- 基于肩部、腰部、膝盖和脚踝关键点动态绑定服装
- 使用 Three.js / WebGL 增强魔法阵、粒子、体积光和水晶材质
- 加入人物分割与前后遮挡，让服装真正贴合真人身体
- 增加声音、动作容错、倒计时与变身完成度

## 设计原则

项目受到经典真人魔法少女“分阶段变身仪式感”的启发，但服装、符号、文案和视觉设计均采用原创方案，不直接复刻具体影视作品。
